# Publishing Media Policy

Keep manuscript, canon and art briefs in Git where appropriate. Keep private print masters, lossless audio, editable design sources and review packages in approved private storage. Drive is for review, handoff and recovery; product delivery uses approved channel storage or versioned web renditions.

Every cover, illustration, map, audiobook, trailer and social crop has an asset ID, version, source, creator/tool provenance, rights/consent, checksum, approval, accessibility metadata and placement. Only approved immutable renditions publish. Generated images may not contain factual cover text, partner marks, ISBNs, quotes or platform badges; composite those exact elements deterministically.
